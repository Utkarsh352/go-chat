## 🚀 Quick Start

### Prerequisites

- Node.js 16+ / Python 3.8+ (depending on your project)
- Git

### Installation

```bash
# 📥 Clone the repository
git clone https://github.com/Utkarsh352/go-chat.git

# 📂 Navigate to project directory
cd go-chat

# 📦 Install dependencies
npm install
# or
pip install -r requirements.txt
```

### 🎯 Usage

```bash
# 🏃‍♂️ Run the project
npm start
# or
python main.py
```
